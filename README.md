# Mis mods de Minecraft (Forge 1.20.1)

Cada carpeta es un mod independiente (Forge 47.4.10, Java 17):

- `casino/` — fichas, cajero, Ruleta de la suerte y Mesa de Plinko.
- `pooltable/` — mesa de billar (1–6 jugadores, 4 modos).

GitHub compila cada mod en cada cambio (pestaña **Actions**); el `.jar` queda descargable ahí.
